# Task Tracker

Projeto em Java para gerenciar tarefas pelo console, com controle de progresso e datas automáticas.
 
---

## Funcionalidades

- **Adicionar** tarefa com nome, descrição e progresso
- **Listar** todas as tarefas
- **Remover** tarefa com confirmação
- **Filtrar** tarefas pendentes ou finalizadas
- **Atualizar** o progresso de uma tarefa
---


## Conceitos aplicados

POO, encapsulamento, getters/setters, ArrayList, for-each, filtro por status e `LocalDate` para datas automáticas.
